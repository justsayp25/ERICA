# E.R.I.C.A. — Emergency Response & Immediate Contact Alert

A privacy-first mobile application for discreet, one-motion personal-safety
alerting and live-location dispatch to trusted contacts, with an offline SMS
fallback. Proposed by Jesse Manuel Pimentel, BS Criminology, University of the
Cordilleras, Baguio City, as a public-safety and crime-prevention tool.

Full concept paper: kept in the author's private notes vault (academic
concept draft, not yet public).

## Status

Concept / pre-implementation. Framework choice (React Native + Expo vs.
Flutter) is not yet locked. No app code has been written yet.

## Origin and licensing note

This project's *design* was informed by reviewing
[dhilipmpms/SOS-alerter](https://github.com/dhilipmpms/SOS-alerter), an
existing GPL-3.0 Android SOS app, for ideas on trigger mechanisms and
offline-first SMS dispatch. **No code from that project is copied here.**
SOS-alerter is GPL-3.0 (strong copyleft) — reusing its code would legally
require this project to also be GPL-3.0. E.R.I.C.A. is a clean-room
implementation: only the *concepts* are reused, none of the source, and it
ships under its own license below.

## Core principle

Help should be one motion away, even when the user cannot speak or see the
screen.
